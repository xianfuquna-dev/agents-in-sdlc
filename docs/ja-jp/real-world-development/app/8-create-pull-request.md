フィルター機能の実装、指示の更新、スキルの更新、品質保証 (QA) プロファイル、テストを 1 つのブランチに保存しました。これらをまとめてレビューし、プルリクエストを開きます。星評価のプルリクエスト (PR) は自分でマージしましたが、今回は **Agent Merge** にプロセスの管理を任せます。

> [!NOTE]
> 通常は、機能、指示の更新、スキルの更新、QA エージェントをいくつかの別々の PR に分けます。ワークショップを簡潔に進めるため、フィルター機能と品質ワークフロー全体を 1 つのセッションとブランチで進め、すべての作業をこの PR にまとめました。

このレッスンでは、次のことを行います。

- Agent Merge の概要と、マージのライフサイクルを自動化する仕組みを学びます。
- 機能の PR 全体と検証の証拠を確認します。
- レビュー後にのみ Agent Merge を許可し、PR がマージされたことを確認します。

## シナリオ

フィルター機能のワークフロー全体を通じて、Copilot を使って機能の計画、実装、検証を行いました。Tailspin Toys は、マージの承認を開発者の管理下に置きながら、残りの PR 作業を自動化したいと考えています。

## Agent Merge の概要

**Agent Merge** は、GitHub Copilot app でプルリクエストをマージするまでに必要な残りの作業を自動化します。有効にすると、アプリのセッションがプルリクエストを読み取り、失敗した継続的インテグレーション (CI) チェックの修正、レビュー コメントへの対応、必要に応じたリベースなど、マージを妨げている問題に対処します。GitHub が許可するとすぐにマージします。バックグラウンドで実行され、アプリを再起動しても継続し、プルリクエストがマージされると自動的に無効になります。

ここまでは、自分で **Merge pull request** を選択していました。Agent Merge に任せることもできますが、コードの編集やマージには引き続き明示的な承認が必要です。マージの許可を与える前に、許可される操作と作業内容をレビューしてください。

## Agent Merge で PR を管理する

コードの作成とレビューが完了したので、Agent Merge に PR プロセスを管理させましょう。

1. エージェント ピッカーで **Default agent** を選択します。
2. **Create PR** の横にあるドロップダウンを選択します。
3. **Agent Merge** を選択します。ボタンが **Agent Merge** に変わります。
4. **Agent Merge** ボタンを選択してプロセスを開始します。ドロップダウンのオプションを選ぶだけでは開始されません。

Agent Merge のプロセスが始まり、次の処理を行います。

- タイトルと説明を含むプルリクエストを作成します。
- Issue からセッションを開始した場合は、説明本文で関連する Issue を参照します。
- リベースを行うか、ターゲット ブランチとのマージ競合に対処します。
- CI プロセスを監視し、すべてのチェックが成功することを確認します。
- 他の開発者や Copilot code review からのフィードバックがないか PR を監視し、コメントを解決するために更新します。
- すべてのチェックなどが成功した後、PR を自動的にマージできます。

すべての条件を満たしたら、Agent Merge に PR もマージさせましょう。

5. マージを許可する前に、PR の差分と検証の証拠をレビューします。
6. **Agent Merge** の横にあるドロップダウンを選択します。
7. **Merge pull request** の横にチェックが付いていることを確認します。
8. 次のように明示して、エージェントにマージを依頼します。

    ```plaintext
    Merge the PR once all required checks and approvals pass. Do not bypass repository protections.
    ```

9. エージェントの進行状況を確認し、報告された問題を解決します。続行する前に、PR のステータスが **Merged** になっていることを確認してください。マージ権限が有効になっていることや、エージェントが動作中であることだけでは、マージ完了の確認になりません。

> [!IMPORTANT]
> Agent Merge は、リポジトリの保護や権限不足を回避しません。続行する前に、それらの問題を解決してください。
